Options Overview

SLR Translator v3 ships with exactly two translation engines. Both translate from Japanese to English, and both are registered by the built-in SLR Engine Wrapper core module:

EngineTalks toTypical useDetails
SLR One or more Sugoi Translator servers (by default a server on your own machine at localhost:14366) Fast, fully offline machine translation once the server runs Sugoi Translator
DSLR Any OpenAI-compatible LLM chat endpoint, local or online LLM translation quality, glossary support, heavy automation DSLR Translator and LLM & Online APIs
No other engines are built in. The base engine class contains a large generic language table, but both shipped engines only declare Japanese as source and English as target — everything in the app is tuned for that pair.

Where engines are configured

Engine settings live in the Options window, under the Translator & Language tab. This tab contains:

  • Default Translator Engine — a drop-down listing every registered engine.
  • One submenu entry per engine (named SLR and DSLR), each opening the engine's full option form.

The DSLR form is large, so it is organized into collapsible sections: Connection & Model, System Prompt & Context, Sampling & Generation, Retry & Quality Control, Glossary Extraction, Caching, Batching & Limits, Text Processing, Placeholders, Patterns, Prompts and Custom Presets. Options that exist separately for the primary model, the fallback model and the glossary extractor are grouped under those roles inside each section.

Options are saved automatically when changed. Because the forms are large, a filter toolbar sits above them: Filter options by name or description... narrows the form as you type, Show changed only hides options still at their default, and Expand all / Collapse all fold the sections. DSLR additionally offers three Options Preset slots (JSON blobs with an Apply Custom Preset button each) and a Reset All Options to default button, so you can keep several configurations — for example one for a local model and one for an online provider — and switch between them.

Default engine vs. per-project engine

The engine is resolved in this order:

  1. The engine chosen in the batch translation dialog for that run (see Batch Translation).
  2. The project's own engine: Project Properties → Language → Translator. Leave it at -use default- to follow the global setting.
  3. The global Default Translator Engine from the options window.

The resolved engine is what Ctrl+G uses to generate a translation for the selected cell(s) in the editor (see Editor Basics). If neither a project engine nor a global default is set, the app prompts you to configure one before translating.

Language and direction settings

Source and target language are resolved per project (Project Properties → Language → Translate From / Translate Into) with global fallbacks that default to Japanese and English. Two dedicated switches in the Options window under General control the direction processing:

  • Japanese Source Language — optimizes the pipeline for Japanese source text (enabled by default; must be disabled when translating from another language).
  • English Target Language — same for English as target.
Both switches require restarting SLR Translator to apply. Translating other language pairs is experimental: besides flipping the switches you must adjust the DSLR prompts and text-processing patterns yourself.

Also under General: Max Concurrent Batches sets how many batches are sent at once to engines that do not manage their own request pool (SLR). DSLR ignores it in favor of its per-endpoint weights. This setting needs a restart as well.

Picking a setup

  • Fully offline: SLR with a Sugoi server on localhost, or DSLR with a local model server such as LM Studio on 127.0.0.1:1234. Nothing leaves your machine.
  • Online: DSLR pointed at a hosted API provider. See LLM & Online APIs for remote endpoints, keys and privacy implications.

For setup steps see Translator Setup; to translate whole projects automatically see Batch Translation and Glossary Extractor.
