Context Translation

Sometimes the same Japanese text needs different translations depending on where it appears — a word that is a name in one scene and a joke in another. Context translation lets one row carry, in addition to its normal translation, a separate translation per place the text occurs. The occurrence-specific translation wins only where it applies.

What a context is

Every row remembers where its text was found in the game: a slash-separated address such as Map003/events/4/pages/1/message, stored per row. The Row properties entry in the grid's context menu lists all contexts of the selected row, and the footer shows them for the current cell. Rows whose text appears in more than one place are marked with a small icon in the row header; the icon turns red once a context translation exists for that row.

Writing context translations

  1. Select a row in the grid. The pane below the grid shows two tabs on the right: Default translation and Context translation.
  2. Switch to the Context translation tab. It lists every occurrence of the row's text with two columns: Context path (write-protected) and Translation.
  3. Type a translation next to the context(s) that need a special one. Empty cells show ~use default translation~ — an empty cell simply falls back to the row's normal translation, so only fill in the occurrences that differ.

The Context path cells cannot be changed (edits are discarded), but their text can be copied: double-click a path to open it and mark the part you need (or click the cell once and press Ctrl+C to copy the whole address), then close the editor with Esc.

When the translation is applied, each occurrence is looked up by its full context first; if a context translation exists for that exact occurrence it is used, otherwise the row's default translation is written. Other rows and other occurrences are unaffected.

The trash button on the Context translation tab clears the context translations of the current row (after confirmation). Alt+Del or the grid context menu's Clear Context Translation does the same for whole selections. Clearing context translations never touches the normal translation columns.

Context translations are included when importing another project: enable Import the context translations in the import dialog. Entries are matched by original text, file and context address, so they only transfer onto the same text at the same place.

The Context Tool

The Context Tool entry in the More Tools toolbar menu opens a different, complementary dialog: it removes rows from the project based on where they came from. Use it to trim a project down to the part you are working on (for example, one map or one chapter) before batch translating.

The dialog lists every context keyword found in the project with the number of rows using it. Keywords are the non-numeric parts of context addresses — map names, event types, parameter names.

  • Select Context(s): click keywords in the list. Hold Ctrl to pick several.
  • Manual Query: type your own keywords, one per line, instead of (or in addition to) the list selection.
  • Action: Remove selected deletes every row whose context contains any of the keywords; Remove all but selected keeps exactly those rows and deletes everything else.

Press Ok to run the chosen action; a confirmation dialog shows the keywords before anything is deleted.

Match all words

By default each keyword (each line of the manual query) is matched as a case-insensitive substring anywhere in a row's context: the keyword school matches Map012/events/3/pages/1/message if "school" occurs in it, and also matches schoolhouse.

Enable Match all words to tighten this: then every whitespace-separated word of a keyword line must appear in the row's context, each as a whole word (case-insensitive, matched on word boundaries). A query line school rooftop matches a context containing both "school" and "rooftop" in any order, but not a context containing only one of them.

  • Without the checkbox: one line = one substring that must occur in the context.
  • With the checkbox: one line = several whole words that must all occur in the context.
  • Several lines (or several selected keywords) are always alternatives — a row matching any line is selected.
The help icon next to the Match all words checkbox opens this section of the documentation.
