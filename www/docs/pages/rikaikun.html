Japanese Dictionary Popup

The built-in Rikai dictionary (a rikaikun-style popup) shows the reading and English definition of Japanese words when you hover over Japanese text in the editor — look up a word without leaving the grid. It works fully offline: the word, name and kanji dictionaries are bundled with the application.

Activating the dictionary

  • The Rikai button in the toolbar toggles the dictionary. When active, the button appears checked and a help popup with the key bindings appears once.
  • The dictionary is enabled automatically on application start unless you disable Enable on startup in the button's side menu.
  • The side menu also offers Never unload dictionaries from RAM: by default the dictionary data is released from memory when you deactivate the dictionary, and reloading it takes a moment. Keeping it loaded makes re-activation instant at the cost of memory — the bundled dictionary data is large.

Using the popup

With the dictionary active, pause the mouse over any Japanese text in the main window — a cell in the grid, text in the cell editor — and a popup appears after a short delay, showing the word under the cursor with its reading and English definitions. Double-click the popup to close it.

The popup keys, once it is visible:

KeyAction
Alt+RDisable / enable the dictionary
AAlternate popup location
YMove popup location down
CCopy word data to the clipboard
DHide / show definitions
Shift+EnterSwitch dictionaries
BPrevious character
MNext character
NNext word
JScroll definitions back
KScroll definitions forward

The popup shows up to seven dictionary entries per lookup. Hovering a kanji character and switching dictionaries cycles through the word dictionary, the kanji dictionary and the name dictionary.

Dictionary contents

  • Word dictionary: Japanese words with readings and English definitions. Conjugated verb and adjective forms are looked up through a de-inflection table, so hovering a conjugated form still finds the dictionary entry.
  • Character dictionary: per-character information for kanji — readings, meanings and reference codes from several kanji reference systems (Heisig, Nelson, Halpern, Henshall, Tuttle, PinYin, Unicode and more).
  • Name dictionary: Japanese personal and place names.
The dictionary popup is a reading aid for the translator, not a translation feature: nothing it shows is written into the project. For checking the English side of your work, see Spell Checking.
