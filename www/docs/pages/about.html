About, Credits & License

SLR Translator is a desktop tool for translating RPG Maker games (XP, VX, VX Ace, MV and MZ) from Japanese to English. It extracts a game's text into an editable grid, translates it manually or with a translation engine, and patches the translations back into a playable copy of the game. An introduction to the workflow is in Overview & Requirements.

Key bundled technologies

  • NW.js — the desktop application runtime (Chromium + Node.js) the whole tool is built on. The About tab shows the exact bundled NW.js, Node.js and architecture versions at runtime.
  • jQuery (1.12.x) — UI plumbing, dialogs and DOM handling.
  • Handsontable — the spreadsheet-like translation grid.
  • Ace — the code editor used by the script editor, automation editor and option fields (see Script Editor).
  • PHP and Ruby helper runtimes — bundled interpreters used by the translation pipeline; nothing needs to be installed separately.
  • ONNX Runtime (onnxruntime-node 1.27.x) with PP-OCR models — the on-device OCR behind SEP picture translation, plus opentype.js for drawing the translated text back onto images (see SEP Picture Translation).
  • mtl-text-processor — the sentence splitting and placeholder protection library used by the DSLR engine (see Escape & Text Codes).
  • nspell — the offline English (en-US) spell checking engine (see Spell Checking).

Helper tools in the 3rdParty folder — included for convenience, under their own licenses — are TES-Patcher by Sinflower (github.com/Sinflower/TES-Patcher), the RGSS archive decrypter, the Enigma Virtual Box unpacker, MeCab, the RPG Maker translation CLI tools and a few small Windows utilities. The Sugoi Translator server that the Sugoi engine talks to is not bundled; it runs separately (see Sugoi Translator).
