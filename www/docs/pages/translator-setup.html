Translator Setup

SLR Translator ships with two translation engines: SLR (SugoiV4 legacy) and DSLR (recommended) (an LLM endpoint). Both translate Japanese to English. This page explains where to select an engine and what each one needs before it can translate.

Choosing the default engine

  1. Open the Options window from the More Tools menu (or press the Translation Setup toolbar button, which opens it on the DSLR engine panel).
  2. Open the Translator & Language tab.
  3. Pick an engine under Default Translator Engine.

The default engine is used whenever you press Ctrl+G on selected cell(s) to generate a translation. It is stored in the global configuration and applies to every project that does not pick its own engine.

Choosing an engine per project

A single project can use a different engine:

  1. Open More Tools → Project Properties.
  2. Set the Translator field. Leave it empty (-use default-) to follow the global setting.
If Translator is not defined in the project, the global default is used.

Available engines

SLR (SugoiV4 legacy)

Listed in the engine picker as SLR (SugoiV4 legacy) (internally still engine id slr). Translates through one or more Sugoi Translator servers using the original Sugoi V4 NMT models — this is not the newer "Sugoi" LLMs.

  • Runs against a Sugoi Translator server, by default on your own machine at localhost:14366. With a local server the whole pipeline is offline.
  • Key options: Sugoi Translator URLs (one URL per line — load is balanced across servers), Request Character Limit, and Maximum Request Count.
  • This engine predates the LLM support and is kept for existing setups. For new projects prefer the DSLR engine below.

DSLR (recommended) — LLM endpoint

Listed in the engine picker as DSLR (recommended). Translates through an OpenAI-compatible chat endpoint, local or online.

  • Point API URL at your endpoint. The default (127.0.0.1:1234) matches a local LM Studio server; other local backends and online API providers work too. To use several endpoints at once (for example multiple accounts at one provider), add them with + Add Endpoint in the engine options — see Parallel endpoints and fallback.
  • Set API Key if your provider requires one (leave blank for most local servers), and Model to the model the endpoint should use.
  • Optional: a fallback LLM that takes over when the primary model gets stuck, plus sampling options such as temperature.

The quickest way there is the Translation Setup button in the main toolbar, which opens this window directly on the DSLR engine panel. Its Quick Start box at the top has just the three fields you need — API URL, API Key and Model — plus a Test connection button that sends a one-token request to confirm they work. The shipped defaults are only an example LM Studio setup with a weak model, so change them unless you really are running LM Studio locally. Every other option is optional.

Configuring an engine

In the Options window, every engine gets its own settings page with its full option form, listed under Translator & Language. Options are saved automatically, and you can store several named configurations per engine and switch between them from that page.

Offline or online?

  • Fully offline: SLR with a local Sugoi server, or DSLR with a local endpoint such as LM Studio. Nothing leaves your machine.
  • Needs a connection: DSLR pointed at an online API provider (or Sugoi servers hosted elsewhere). The network is only used to reach the engine you configured — parsing, editing and applying translations never require it.
The source and target languages are controlled globally in Options under General (Japanese Source Language / English Target Language). SLR Translator is optimized for Japanese to English; other pairs are experimental and require adjusting the engine prompts.

Once an engine works, continue with Your First Translation Project, or read Batch Translation to translate whole projects automatically.
