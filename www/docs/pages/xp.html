RPG Maker XP

XP is the oldest supported engine. It is an RGSS1 game: the data is Ruby-marshaled in the Data folder with the .rxdata extension, and Game.ini names the RGSS1 runtime. XP uses the same parser and the same workflow as RPG Maker VX Ace and RPG Maker VX — read those pages for the full walkthrough.

Recommended workflow: generate a glossary → run the full Batch Translation (dialogue is grouped scene-aware automatically via the Scene Graph) → review the flagged rows → wrap the text automatically → export.

Creating the project

  1. In the wizard, choose RPG Maker XP, VX, Ace, MV & MZ Parser and select the game's executable. rmxp is detected from the RGSS1 entry in Game.ini (see Engine Detection).
  2. If the game is packed as a Game.rgssad archive, the wizard forces a development copy and decrypts the archive into it — see Encrypted & Packed Games.
  3. Click Create project!. The .rxdata files are unpacked into YAML, the scripts into readable Ruby files, and the project opens in the editor.

XP specifics

  • Data files: the same database set as VX and VX Ace, with the .rxdata extension (Actors.rxdata, Map###.rxdata, and so on). Names, descriptions, messages, notes and event command lists are extracted; Animations and Tilesets are skipped.
  • Scripts: parsed into editable Ruby objects like on VX and VX Ace. The virtual Scripts/!Main Injection object is not available for XP — to change runtime settings such as the default font, edit the affected script strings in the script objects directly, or use the Script Editor.
  • Encoding: Japanese XP games often use legacy encodings; the tool converts them transparently — see Japanese Locale Configuration.

Applying and exporting

Identical to VX and VX Ace: Export Project → Export to a folder or Export as a Zip file, with the tagged-rows filter and Word Wrap By Tag rules (export-time rules, distinct from the Automatic Word Wrapping button) in the Export Options dialog; on export the translated YAML is repacked into .rxdata files and the scripts are recompiled — see RPG Maker VX Ace: Applying and exporting.

Selecting a row and opening the raw data viewer shows a decoded header (event name, page, command), the unpacked YAML with the row's text highlighted, and a data tree of the file — see Cell Info Panel.
