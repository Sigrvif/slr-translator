General Settings

The Options window has three entries in its left menu: Translator & Language (which engine Ctrl+G uses — see Options Overview), General, and About. This page documents the General tab option by option. The search box at the bottom of the menu filters the entries by name.

Option reference

OptionWhat it doesDefault
Staging Directory The working cache for open projects: while you work on a game, a portion of its data is copied here for the interpreter scripts to access. Changing it asks for confirmation and then offers to move the existing staging content to the new location. Point it at a fast disk with enough space for your projects (see Your First Translation Project). www/php/cache inside the application folder
File Association — trans, tpp Registers the file types .trans and .tpp so double-clicking such a file opens it with SLR Translator. Set All / Unset All toggle every checkbox; Apply writes the association into the Windows registry after a confirmation prompt. not associated
Backup — Enable backup When on, every save of a .slrproj project first rotates the previous file into a backup copy named <project>.slrproj.1.bak, shifting older backups up (.2.bak, .3.bak…). The oldest backup beyond the configured level is deleted. Turn this off only if you make your own backups (see FAQ & Tips). on
Backup — Backup level history How many backup generations to keep per project, from 0 (no backups even when enabled) to 10. 1 (fresh installations write 3)
Max Concurrent Batches How many translation batches are in flight at once, for engines that do not manage their own endpoint pool (for example the Sugoi engine). The DSLR engine ignores this and uses its per-endpoint weights instead (see Batch Translation and DSLR Translator). Requires a restart to apply. Caution: raising it above what the translation server can handle gains nothing or breaks the run. 1 (range 1–20)
Japanese Source Language Declares that source text is Japanese. Many checks and processing rules are Japanese-specific; support for other source languages is experimental and requires adjusting all DSLR prompts and wrapper patterns. Disable this when translating from any other language. Requires a restart to apply. on
English Target Language Declares that the target language is English; same experimental status and the same prompt adjustments needed for other targets. Disable this when translating to any other language. Requires a restart to apply. on
Log & Debugging — Log to file Mirrors the log to the developer console and writes it, expanded, to a file in the data/logs/ folder. Enabled by default so a log exists when you report a problem; it costs a little performance. Requires a restart to apply. on
Log & Debugging — Keep last sessions (rotate) Rotates the log file each session instead of appending forever: the current session is the main log, the previous two are kept as .1 and .2 backups, older ones are deleted — three sessions in total. Requires a restart to apply. on
Log & Debugging — Log Options window to its own file Lets the Options window write its own options.log next to trans.log. It mostly repeats what the main log already records, so it is off by default; enable it only when debugging an Options window problem. Requires a restart to apply. off
Options marked “requires a restart” prompt you to restart SLR Translator when changed; the new value only takes effect after that restart.

Sections added by core modules

Below the built-in options, the General tab grows extra sections from installed modules that declare general options. In the default installation these are:

  • SLR Batch — batch translation defaults (see Batch Translation).
  • Spell Checker — the offline English (en-US) spell checking options (see Spell Checking).
  • Appearance — the night mode (dark UI) toggle. Night mode recolours the whole interface, including the drop-down lists and multi-select list boxes of select fields and the native tick of checkboxes and radio buttons, which are drawn by the browser separately from the page and would otherwise stay white or turn orange. Text selection keeps the blue highlight everywhere, including the Default translation editor.

Modules with their own full tab (such as SEP, the picture translator — see SEP Picture Translation) appear as separate entries in the left menu instead. User addons can add sections the same way; see User Addons.

The other menu entries

  • Translator & Language — picks the engine used by Ctrl+G on selected cells, and hosts every engine's own options tabs. See Options Overview.
  • About — version, license and credits summary. See About, Credits & License.
