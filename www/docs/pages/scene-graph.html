Scene Graph

The Scene Graph is the tool's dialogue tracing: it reconstructs how the game's text is actually played. Every extracted row is mapped to a scene (a contiguous block of dialogue in play order), its position inside that scene, and its speaker — including links across files, such as a map event calling a common event that shows the rest of the conversation. The graph is built from Map*.json and CommonEvents.json for MV and MZ projects, and from the staged YAML data for XP, VX and VX Ace projects. Protected MV/MZ games whose data/ files are encrypted containers are decrypted automatically for the graph build (see Encrypted & Packed Games).

Its main job is invisible: during Batch Translation it keeps dialogue that belongs together in one translation request, so the engine sees whole conversations instead of shuffled single lines.

The Scene Graph supports all built-in RPG Maker engines: MV, MZ, XP, VX and VX Ace. XP/VX/VX Ace projects need their staged YAML data (created automatically when the project is made through the RPG Maker XP, VX, Ace, MV & MZ parser), so projects imported through other routes translate normally but without scene tracing.

When it is built

  • The graph is built automatically every time a project is created or opened — there is no build button and nothing to configure.
  • After project creation the Scene Graph panel opens on its own, so you can see the traced structure right away. On later opens it stays closed until you call it up.

The Scene Graph panel

Open it any time with the View Scene Graph (dialogue tracing) button in the extra toolbar (the share icon). The panel is a floating, draggable window that shows the traced scenes with their rows in dialogue order and the speaker of each line, plus a summary line of the form X scenes · Y rows mapped.

  • Click a scene or a line to jump straight to that row in the grid — a quick way to see a conversation in context before translating it.
  • The scene and speaker information also feeds the DSLR engine's prompt when its Scene Context option is on (see below).

Scene-aware batch translation

During Batch Translation the Scene Graph works automatically — there is no toggle. For every run on a supported engine:

  • Rows are re-sorted into dialogue order, so batches follow the flow of the game instead of file order.
  • Batches are then built in four streams:
    1. Big scenes are sent whole, isolated in their own requests — a coherent large request gives the model the full conversation and is actually less likely to fail than a fragmented one.
    2. Small related scenes are grouped to fill sensible requests. Scenes count as related when they share an event or event page, are linked by a common-event call, call each other, or connect through map transfers.
    3. Single-line scenes (one-off NPC remarks, object descriptions) carry almost no internal context, so they are packed densely without hurting quality.
    4. Non-scene rows — menus, items, skills, system terms — are batched last.

This is why running the full project through Batch Translation is the recommended default rather than translating line by line: the model sees each line with its conversation around it, which single-line requests can never provide.

DSLR scene options

The size limits of the four streams are DSLR engine options (they mainly matter for DSLR runs; other engines use safe fallbacks). All of them live with the DSLR settings — see DSLR Translator:

OptionDefaultControls
Maximum Scene Size5000The largest a single standalone scene may be, in characters. Long scenes are isolated and sent whole up to this size; only a scene genuinely exceeding it is split, and only at scene boundaries.
Target Request Size2000The comfortable request size for everything that is not a standalone large scene: grouped small scenes and non-scene text pack up to this size.
Scene Threshold15Scenes with fewer rows are considered short and merged with adjacent scenes; scenes at or above it are isolated and sent whole.
Max Scenes per Grouped Batch7How many separate scenes may be merged into one grouped batch, to cap context bleed.
Max Rows per Non-Scene Batch80Row cap for batches of non-scene text (menus, items, system terms).
Max Rows per Single-Line Scene Batch40Row cap for batches packing one-line scenes, which tolerate much denser packing than real conversations.

Scene Context in the prompt

With the DSLR option Scene Context (default on), a per-batch description of the scene each line belongs to — dialogue flow, speaker names, cross-file common-event links — is appended to the system prompt, giving the model awareness of the conversation it is translating. (When the DSLR option KV-Cache Friendly Prompts is on, the scene description is sent as part of a separate context message instead of the system prompt — see DSLR Translator.) Disable it if a model struggles with the extra context, or produces poor results with it. The Context Length Limit option can trim scene context automatically so weak models do not run out of context window.
