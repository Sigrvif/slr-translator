Sugoi Translator

SLR (SugoiV4 legacy) is the engine that translates through one or more Sugoi Translator servers. It is the original Sugoi V4 neural machine translation (NMT) line — unrelated to the newer "Sugoi" family of LLMs. It sends batches of Japanese strings to each server and inserts the returned English strings into the target column. It only supports Japanese as source and English as target — if the project specifies other languages, the engine logs a warning and translates as Japanese to English anyway.

Requirements

  • A Sugoi Translator server that is running and reachable. The engine expects it on your own machine at localhost:14366 by default.
  • With a local server, the entire translation pipeline is offline: parsing, translating and applying never touch the network beyond your machine.
SLR Translator only acts as the client — it sends translation requests to whatever address you configure. Setting up and starting the Sugoi server itself is done outside this application and is not covered by these docs.

Configuring

Open Options → Translator & Language → SLR (SugoiV4 legacy). The engine has three options:

OptionDefaultMeaning
Sugoi Translator URLs one entry: localhost:14366 (the full address SLR uses is localhost:14366 on default server paths) One server address per line. Requests are balanced across all listed servers so that every server holds roughly the same number of open requests.
Request Character Limit 5000 Maximum characters sent per server request. Larger values are faster as long as the server's memory keeps up. A single string that cannot be split and exceeds the limit is still sent, but alone in its own request.
Maximum Request Count 1 How many requests may be in flight at the same time. The option text suggests roughly two per server as a starting point.

How requests work

  • Rows are packed into batches up to the character limit and posted to a server as a JSON payload containing the text array.
  • The server must answer with a JSON array of the same length. If the lengths do not match, the whole batch is discarded with an invalid response - length mismatch error (usually a sign of an unstable or crashed server).
  • With Japanese Source Language enabled (the default), the engine masks SLR placeholder tokens and strips characters that cannot be Japanese before measuring text, which keeps batching decisions based on actual Japanese content.

Using SLR

  • Manual: select cell(s) in the editor and press Ctrl+G to generate translations — see Editor Basics.
  • Whole project: the Batch Translation dialog lets you pick SLR for the run regardless of the default engine.

Error behavior

  • A failed request (server error, invalid response, network problem) is logged and counted — the progress readout shows (N failed translations) — but the remaining batches continue. Failed rows are simply left untranslated.
  • The log message for a failing server reminds you to check whether that server is still up.
  • Translation runs can be paused and aborted from the progress overlay.

Limitations

  • Japanese to English only.
  • No glossary injection, scene context, retry-with-correction or other LLM features — those belong to DSLR.
  • Translation quality is fixed by the server's model; none of DSLR's prompt or sampling options apply.
