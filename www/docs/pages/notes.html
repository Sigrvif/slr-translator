File Notes

Every entry in the Objects panel — every parsed file of the project — has its own note: a free-text memo with an optional color. Use notes to record where you stopped, what still needs checking in that file, or anything else worth remembering next time you open the project.

Opening and editing a note

  1. Select a file in the Objects panel.
  2. Click the note button (the speech-bubble icon) in the toolbar. A small Note window opens for the selected file — its title bar shows the file it belongs to. Clicking the button again closes the window.
  3. Type your note. It is saved into the project as you edit; there is no separate save button. A note holds up to 4096 characters.
  4. The trash button at the top of the window clears the note and its color.

The window stays open while you work; switching to another file in the Objects panel switches the note window to that file's note.

Note colors

The -Default- selector at the top of the note window picks a named color for the note. The color is only a visual marker — it does not change any behavior — but it is shown wherever the note is indicated, so you can use it to flag priority at a glance.

Where notes are visible

  • Files with a note show a comment icon next to their name in the Objects panel, tinted with the note's color if one was set.
  • Hovering such a file entry shows the note text in a tooltip, so you can read it without opening the note window.
  • The note button in the toolbar reflects the state of the currently selected file.

Where notes are stored

Notes are part of the project data and are saved into the project file together with everything else — they survive closing and reopening the project, and they are included when you share a .slrproj file.

Notes are per file. For remarks attached to a single cell, use cell comments instead: right-click the cell in the grid and choose Add comment. Cell comments can be searched from the Find window with Target: Comment — see Find & Replace.
