Spell Checking

SLR Translator includes an offline spell checker for your English translations. It uses a bundled English (en-US) dictionary and works entirely without a network connection.

What it checks

As you type in the cell text editor — the Default translation pane below the grid — misspelled words are underlined with a red wavy line, live while you edit. The check runs only in that editor pane; the grid itself is not decorated.

The checker is deliberately lenient with translation content:

  • Words shorter than two letters are never flagged.
  • Words containing digits are never flagged.
  • Words written in ALL CAPS are treated as acronyms and never flagged.
  • Words on your whitelist (below) are never flagged.
Very long texts (over 20,000 characters) are not checked — the checker pauses rather than slow the editor down on huge cells.

Enabling and disabling

The options live in the Options window, in the Spell Checker section:

  • Enable spell checker — turns the underline on or off. Enabled by default.
  • Extra allowed words — a comma-separated list of words that should never be flagged: character names, place names, game-specific terms.

Changes to these settings are applied the next time the application starts.

Limitations

  • English only, using the bundled en-US dictionary — other languages are not checked.
  • The checker marks misspellings; it does not offer corrections. Fix the word yourself (the Japanese dictionary popup described on Japanese Dictionary Popup can help with the original text).
  • Only the cell text editor is checked, not translation columns shown in the grid. To review finished translations, open each cell (or use Find & Replace to spot suspicious patterns).
