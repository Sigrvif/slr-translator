Find & Replace

The Find window searches across every file of the project — the grid itself only shows one file at a time. It can find and replace text, put whole translations, and act on the found rows in bulk.

Opening the Find window

  • Ctrl+F opens it on the Find tab, Ctrl+H on the Replace tab.
  • The Find toolbar button opens it as well; its side menu can bring an already open Find window back to the front.
  • If text is selected when you open the window, it is pre-filled into the search fields and searched immediately.
  • The window keeps a history of your last keywords (up to 100), offered as suggestions while typing. Its slider menu toggles Always on top and the background Blur opacity.

Inside the window, Enter runs the command of the visible tab, and Alt+Enter inserts a line break into the field you are typing in — all five fields accept multi-line text, so you can paste or type a whole multi-line cell to find, replace or translate it as one block. For quick lookups in the file currently loaded in the grid, use the Quick find box in the toolbar instead — it highlights matches live as you type.

Find

Type a keyword and press Enter. A keyword may span several lines (Alt+Enter), which finds every cell containing that exact sequence of lines — handy to search for a whole multi-line cell. Options:

OptionEffect
TargetWhere to search — hold Ctrl to select several: Grid (all cells of every row), Context (the context addresses of rows), Tag (rows by color tag — the keyword is one or more tag names, space-separated), Comment (cell comments).
Case sensitiveMatch upper and lower case exactly; off by default.
Transpile \r\n\tTurn the escape sequences \r, \n and \t in your keyword into real carriage return, newline and tab characters before searching.
Search all filesSearch the whole project. Uncheck it to open a file selector and drag over the files to search; hold Shift while dragging to unselect.
RegExpTreat the keyword as a JavaScript regular expression (see regular expression tips).

Keywords containing * but not using RegExp are treated as glob patterns (for example *name*).

Results are grouped per file with a count and search time. Click a result to jump to that cell in the grid. Checkboxes in front of the results select rows for bulk actions; Shift-click checks a range. Each result also shows the row's color tags.

Right-click the results for Select all / Clear selection and With selection...: Set Red/Yellow/Green/Blue/Gold tag, More tags... (append, remove or set any tags — see Cell Color Tags), Clear tags, Create Automation, Run Automation, Clear translation, and Delete rows.

Replace

The Replace tab finds a keyword and replaces it with another string in every matching cell. Both fields accept multi-line text (Alt+Enter), so a whole multi-line cell or a run of lines inside it can be replaced in one go. It shares the case sensitivity, transpile, file-selection and RegExp options with Find.

  • Replacement never touches the Original Text column — only translation columns are modified, so the keys that tie rows to the game stay intact.
  • Plain (non-regex) replace replaces every occurrence of the keyword in each matching cell.
  • With RegExp, the replace uses JavaScript semantics: the pattern replaces the first match only unless you add the g flag, and capture groups can be referenced as $1, $2, ... in the replacement.
There is no undo for replace. A confirmation dialog shows exactly what will be replaced with what — read it before confirming, and save the project first so you can fall back to the file on disk.

The result list shows each changed cell before and after; click an entry to jump to it.

Put

The Put tab writes whole translations: enter the original text into Original text (press Alt+Enter for a new line inside the field), the translation into Text to put, and choose the target column with into: (the original text column is not offered). Existing content in the target column is overwritten after confirmation.

  • Single line — every cell containing that line gets the translation written into the matching line of the target column. Matching is on the whole line, optionally case-sensitive.
  • Several lines — the lines are matched as one contiguous block, line-aligned, inside the cell. The same run of lines in the target column is replaced by the text to put, so the rest of an already translated cell is kept. Entering the complete original cell therefore rewrites the whole target cell.

Regular expression tips

Patterns use JavaScript regular expression syntax. Either write the pattern bare ([0-9]+) or as a literal with flags (/foo/gi). Invalid patterns are reported with no search run. Some patterns that come in handy when translating:

PatternFinds
[㐀-䶿一-鿿ぁ-ゖァ-ヺ]Any kanji or kana — run it over your translation columns to find texts that were left (or came back) untranslated. Case-insensitive does not apply; no flags needed.
/\\c\[\d+\]/RPG Maker color codes such as \c[3] — useful to check that control codes survived the translation.
/ {2,}/g as Find with (a single space) as ReplaceCollapses runs of multiple spaces into one across all translation cells.

Searching by color tag

Set Target to Tag to search by tag instead of text: the keyword is one or more tag names separated by spaces, and every row carrying any of those tags is returned. Combine this with the bulk tag actions to review or re-classify rows — for example, find all purple rows after a batch run and re-translate them, or mediumpurple for the DSLR review's findings.

Searching with Target: Tag — the keyword is the tag name.
