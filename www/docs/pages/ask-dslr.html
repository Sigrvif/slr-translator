Ask DSLR a Question

Ask DSLR is a small chat window that talks to the LLM endpoint you already configured for the DSLR translation engine. Instead of reading this documentation, you can just ask it questions — the model has tool access to these very pages and quotes them back at you. It also answers questions the manual does not cover, like how a line could be phrased more naturally.

What it does

  • Opens from the Ask DSLR button in the main toolbar (next to the wrench).
  • Uses your DSLR engine settings (API URL, key, model) — there is nothing extra to configure.
  • Answers manual questions by actually reading the manual pages, citing the page it used.
  • Answers anything else from the model's own knowledge.
  • The assistant's portrait reacts to what you ask: smug when the manual covers your question, delighted when it doesn't. The portrait images can be replaced with your own — see www/core/docsChat/img/.
  • The conversation lives in memory only: closing the window discards it, and nothing is written to disk.

Requirements

A configured DSLR engine (see Translator Setup). The chat works with the bundled local runtime and with remote OpenAI-compatible endpoints. Endpoints that do not support tool calling are handled automatically: the chat searches the manual locally and hands the model the relevant pages as pre-fetched text instead.

The documentation tools

The model is offered three tools, executed locally inside SLR Translator:

ToolWhat it does
list_docsList every manual page with its id, title and section.
read_docRead one manual page in full, as plain text.
search_docsSearch the manual and return the best matching pages with snippets.

Chat options

The chat has a few visible settings in the DSLR engine options (card Ask DSLR Chat, next to the Bundled Local Runtime card) — the serious side of the feature, independent of the assistant's personality:

OptionDefaultEffect
Manual page read length24000How many characters of a manual page the assistant may read at once (documentation excerpts get half). The default is conservative for a 32k context; raise it for models with larger contexts.
Remembered messages20How many past messages are sent along with each new question. Higher remembers more of the conversation but fills the context faster.
Remember chat conversationsonKeep conversations when the chat window or the app closes. Each conversation is its own topic-scoped chat (auto-titled from the first question), so a small follow-up on an old topic never drags unrelated history along. Pressing Ask DSLR first opens a selection dialog — even before any conversation exists, because it also carries the note about what is remembered and the defaults limiting it — listing each remembered conversation with its date (deletable right there) next to Start a new conversation. Conversations are stored prose-only in data/ask-dslr-history.json.
Chat conversations kept20How many remembered conversations to keep; when the limit is reached the oldest are dropped. Raise it to keep old topics around for longer.

Changing the assistant's personality

The assistant's default demeanor is a matter of taste. To change it, open the plain text file data/adp.txt (it is created empty on the first launch) in any text editor and write one of the following as its only content:

ContentEffect
(empty)The shipped default personality.
offNo persona and no documentation tools — a plain chat.
professionalA neutral, professional assistant.
any other textUsed verbatim as the assistant's persona instructions.

It is a plain text file — no JSON, nothing to break. The content is read when each message is sent, so saving the file takes effect on the next message without restarting SLR Translator. Advanced alternative: the same value can be set as the askDslrPersona key in data/config.json; the text file wins. This setting deliberately does not appear in the Options window.
