Cell Info Panel

The pane below the grid is the cell info panel: a larger view of the selected row and its editor. It is shown by default and can be hidden with the Toggle Active Cell Info toggle in the editor toolbar. This page documents what it shows; for the grid itself see Editor Basics.

The panel has two sides. The left side displays the source material of the selected row on two tabs, Original and Raw; the right side holds the translation editor on the tabs Default translation and Context translation (see Context Translation).

The Original tab — text and romaji

The Original tab shows the row's original Japanese text with a reading aid: the romaji transcription is rendered above each segment of the text, furigana-style, so the pronunciation of kanji compounds is available at a glance.

  • The readings are produced by the bundled MeCab analyzer running locally (through the application's built-in PHP helper) — fully offline, nothing is sent anywhere.
  • Readings are cached, so re-selecting a cell you have visited before is instant.
  • The header line above the text shows the row's info text (for example the speaker the line belongs to — see row header info).
  • The small toolbar offers Resize Font, a word-wrapping toggle for non-Japanese text, and Copy original text into current cell — the same thing Ctrl+0 does in the editor (see Editor Basics).
For looking up whole words rather than readings, activate the Japanese Dictionary Popup and hover the text.

The Raw tab — the source data

The Raw tab shows where the selected row comes from in the game's original data. What exactly is shown depends on the engine:

  • VX, VX Ace and XP projects: three parts, top to bottom:
    • a metadata header decoding the row's origin — the file, the event or database entry with its in-game name, the page and command number, and the command type (for example Show Text (bottom, no picture));
    • a source snippet from the unpacked YAML data with the row's text highlighted and the surrounding commands visible. The line numbers are real, so right-clicking the snippet offers Copy path to clipboard, Open folder, Open with external application, and opening the exact line in VS Code or Notepad++;
    • a collapsible data tree of the whole file, expanded near the row's position. Large binary blobs such as the map tile table are collapsed to placeholders so the tree stays usable.
    Rows from Game.ini show the metadata header and the snippet; rows from extracted scripts show the Ruby source snippet with the same right-click options as always.
  • MV and MZ projects: the same metadata header, then a beautified view of the original JSON with the row's command highlighted. The view is reformatted for readability, so its line numbers do not match the file on disk — the right-click menu therefore offers Copy path to clipboard, Open folder and Open with external application but no editor jump. Below the snippet the JSON tree of the file is shown, expanded to the row's position. Plugin and script rows show the plain source snippet with full editor jump, as before.
  • SEP projects: the source image with the row's detected text region highlighted, together with its OCR score — see SEP Picture Translation.
Every selection starts the tab at the top, at the metadata header and snippet — scroll down for the data tree.

The translation editor

The Default translation tab is the main editor for the selected cell — whatever you type here goes into the cell the grid shows. While typing:

  • misspelled English words are underlined live by the offline spell checker;
  • an autocomplete offers words that already exist in the current file, plus known control codes (enter a backslash \ to see them — see Escape & Text Codes);
  • Ctrl+0 … Ctrl+9 insert the content of grid column 0…9 at the caret.

Current Cell Editor options

The gear button (Current Cell Editor options) on the editor's toolbar opens a small popup with two tabs:

  • Markers — vertical marker lines drawn inside the editor at fixed character positions. For each marker you set the position (Mark at), the unit (Half width character for Latin text, Full width character for Japanese) and a color; Add and Clear all manage the list. Use markers to see where a line will visually end — for example at the wrap length you plan to use.
  • Options — Enable suggestion turns the autocomplete described above on or off.

Row emblems

The strip between the two sides shows small emblems for the selected row:

EmblemMeaning
commentThe cell has a comment (searchable — see Find & Replace).
organic contentThe row's translation was written by a human, not produced by a translation engine.
visitedYou have visited this cell before (when the visit trail is enabled — see Editor Basics).
first visitThis is the first time the cell is visited.

Navigating with coordinates

Next to the Go to current cell button there is a small coordinate input (title Current coordinate). Type a row,column pair into it — for example 120,2 — and the grid jumps to that cell. Go to current cell scrolls the grid back to the cell shown in the panel, useful after browsing the raw data or searching.
