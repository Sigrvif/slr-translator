Overview & Requirements

SLR Translator is a desktop tool for translating RPG Maker games. It extracts the text of a Japanese game into an editable grid, lets you translate it manually or with a translation engine, and then writes the translation back into a playable copy of the game.

The main window opens maximized on first launch and remembers its size and position afterwards, so the labelled translation toolbar has room to show its text. If you shrink the window, the toolbar labels collapse back to icons (lowest priority first) and the Start Translation button keeps a short label; hover any button for its full description. The first time the editor opens, SLR also offers a very short tour of the translation buttons, replayable from Tools → Show button tour.

What SLR Translator does

  • Extract — a project wizard parses the game files and lists every translatable text in a spreadsheet-like grid, one row per text.
  • Translate — edit rows by hand, generate translations for selected cells with Ctrl+G, or run the whole project through Start Translation (batch translation).
  • Export — Export Project writes your translations as pre-compiled game data to a folder or a zip archive, ready to drop into a copy of the game.

Besides the translation grid, the built-in core modules provide:

  • Batch translation and a glossary extractor for consistent names and terms.
  • Offline spell checking (English) and a Japanese dictionary popup for the source text.
  • SEP picture translation: on-device OCR that extracts text from game images (PNG/JPG and more) and redraws it, fully offline.
  • Custom text parsers for files that are not plain game data, plus a script editor and automation editor for advanced rewrites.

Supported engines

SLR Translator detects the game engine automatically when you select the game executable, and picks the matching parser:

Detected codeEngine
rmmvRPG Maker MV
rmmzRPG Maker MZ
rmvxaceRPG Maker VX Ace (RGSS3)
rmvxRPG Maker VX (RGSS2)
rmxpRPG Maker XP (RGSS1)

Encrypted or packed games are handled as well: RGSS archives (.rgss3a, .rgss2a, .rgssad) are decrypted automatically during project creation with the bundled decrypter, and Enigma Virtual Box packed executables are unpacked by the tool itself. See Engine Detection for how this works, and the engine-specific pages for details.

Non-RPG-Maker material is also supported: custom parser projects driven by your own regex or JavaScript — which also cover tabular files such as CSV, since ready-made parser models ship with the tool (see Custom Parsers & Model Creator) — and SEP projects for images.

Offline by design

Everything the editor does — parsing, editing, batch tooling, OCR, spell checking, this documentation — runs locally on your machine. The app never contacts the network on its own.

The only component that can use the network is the translation engine you pick: the Sugoi engine talks to a Sugoi Translator server (by default on your own machine at localhost:14366), and the DSLR engine talks to an LLM endpoint, which can be a local server such as LM Studio or an online API provider. If both the engine and its server run on your machine, the whole translation pipeline stays offline. See Translator Setup.

System requirements

  • SLR Translator is a self-contained NW.js desktop application, distributed as Windows and Linux packages. It bundles its own helper runtimes (PHP and Ruby) and third-party tools, so nothing else needs to be installed.
  • Disk space for the game data the tool creates: a staging copy while you work, and the exported translation when you are done.
  • If you plan to run a translation engine, its server or endpoint must be reachable (a Sugoi server or an OpenAI-compatible LLM endpoint — see Translator Setup).
SLR Translator is optimized for Japanese to English translation. Support for other language pairs is experimental; the source and target languages can be adjusted in the Options window, under General.

Where the documentation lives

This documentation ships inside the application and is available offline:

  • Press F1 in the main window, or use the Help toolbar button.
  • Many dialogs and settings pages have a ? help button that jumps straight to the relevant page.
  • The left sidebar of the documentation window lists every page and includes a full-text search.
