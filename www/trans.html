    Import translations from another SLR Project (.slrproj)

    Reuse translations from an existing .slrproj file by matching identical rows. Only rows whose original text already exists in the current project are updated — no new rows are added.

    Ideal for game updates. If a game was re-parsed after an update, this restores the translations you already completed for the text that is still present.

    Source :

    All columns are restored. Every column except the original text (translations, notes, context translations, etc.) is copied from each matching row.
