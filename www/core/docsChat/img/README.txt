The assistant's portrait images live here:

  avatar-neutral.png   - the expression when the chat opens
  avatar-smug.png      - when the user asks something the manual covers
  avatar-happy.png     - when they ask something it doesn't

Replace any of them with your own files (same names). A single file named
avatar.png is used for all three expressions at once; a mood-specific file
always wins over it. jpg, jpeg, webp and gif also work, and square images
look best (shown as 128x128). Changes are picked up on the next message or
after New chat - no restart needed. An expression without a file shows as
an empty portrait box.
