# SLR Translator — source repository

SLR Translator is a GPLv3 translation toolchain (RPG Maker parsers, image OCR,
batch translation, local LLM runtime) built as an NW.js application. This
repository lives **inside the Linux app tree** (`SLR Translator Linux`); the
Windows twin (`../SLR Translator`) carries the same source plus the Windows
runtimes and stays outside git. Shared source — `www/`, `dev/`, `data/`,
`Custom Parsers/` — must remain identical in both trees;
`dev/pack-release.sh` enforces the `www/` half of that rule before every
release.

## What is not in git (and where it comes back from)

A fresh checkout is the *source*, not a runnable app. To reassemble one,
start from a release archive (it contains everything below) and apply source
changes on top — or rebuild the missing layers:

| Excluded | Size | Restore |
|---|---|---|
| NW.js runtime: `nw`, `lib/`, `*.pak`, `icudtl.dat`, `locales/`, `swiftshader/`, `crashpad_handler`, `credits.html` | ~270 MB | Linux: nwjs.io build **89.0.4389.114** (`nw --version`). The Windows tree keeps its own, older pinned build (Apr 2021) |
| `php/` | 16 MB | official PHP distribution zip for the platform (ships its own `license.txt`) |
| `ruby/` | 21 MB | RubyInstaller build (Windows) / bundled interpreter (Linux); vendored sources live in `ruby/src/` |
| `runtime/` | 113 MB | `node dev/update-llama-runtime.js` (currently pinned to build b12110; optional CUDA/ROCm packs are separate release assets) |
| `node_modules/` (root and `www/core/*/node_modules/`) | ~68 MB | `npm install` from the root and each module's `package.json`. **Exception:** `www/core/SLRtrans/node_modules/mtl-text-processor` is tracked — it is a directly-edited vendored package that no longer matches upstream (pristine snapshot: `vendor-source/`) |
| `www/core/SEP/models/*.onnx` | 384 MB | upstream model releases (PaddleOCR PP-OCRv6, LaMa, AOT); the license/notice sidecars next to them are tracked |
| runtime state: `data/logs/`, `data/config.json`, `data/profile/`, `data/llama/{models,slots}/`, `www/php/cache/` | — | self-created at first boot |

## Releases

`dev/pack-release.sh` builds both archives (`SLR Translator v<X>.7z`,
`SLR Translator Linux v<X>.7z`) after checking that both trees agree on the
version and that `www/` is in sync. It excludes `.git` and `vendor-source/`
(collaborator source archives — repo-side provenance, not runtime assets).
